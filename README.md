# Sistema SPA - Gerenciamento de Usuários

## 📋 Descrição
Sistema Single Page Application (SPA) desenvolvido em JavaScript puro para atividade da faculdade. Aplicação com interface dinâmica, validação de formulários e armazenamento local.

## 🚀 Funcionalidades
- ✅ **Single Page Application (SPA)** - Navegação sem recarregar a página
- ✅ **Sistema de Templates** - Renderização dinâmica de conteúdo
- ✅ **Validação de Formulários** - Verificação em tempo real com mensagens de erro
- ✅ **Armazenamento Local** - Persistência de dados no localStorage
- ✅ **CRUD Completo** - Criar, listar e excluir usuários
- ✅ **Interface Responsiva** - Design moderno e adaptável

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage API

## 🎯 Como Executar
1. Clone o repositório
2. Abra o arquivo `index.html` em um navegador web
3. Navegue entre as páginas usando o menu superior
4. Cadastre usuários no formulário de cadastro

## 📄 Páginas da Aplicação
- **Home**: Página inicial com estatísticas
- **Usuários**: Lista de usuários cadastrados
- **Cadastrar**: Formulário com validação para novo usuário
